# Mirsad build: decisions made during the build

The owner asked for routine, reversible decisions to be made without approval rounds. This file lists every ruling recorded in the build ledger, in the order it was made, each with what it costs if it was wrong, followed by the items deliberately left open. The design notes (`docs/superpowers/specs/2026-11-21-mirsad-design.md`) and the README carry the resulting behaviour; this file explains why.
